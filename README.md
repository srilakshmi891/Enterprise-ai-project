# 🤖 AI Enterprise Project Management System

## 📌 Project Description

The **AI Enterprise Project Management System** is an AI-powered application designed to help software development teams manage and access project-related information through a centralized platform.

In enterprise software projects, important information is often distributed across project documents, GitHub repositories, Jira issues, tasks, bugs, and other sources. Finding the required information manually can be time-consuming.

This project provides an AI-assisted interface that allows users to interact with project information using natural-language queries.

The system combines **Generative AI, Retrieval-Augmented Generation (RAG), document processing, semantic search, and project-management integrations** to provide relevant and context-aware responses.

### 🎯 Objectives

- Centralize project-related information.
- Provide an AI-powered project assistant.
- Allow users to ask questions using natural language.
- Retrieve relevant information from project documents.
- Support project information retrieval from GitHub and Jira.
- Use RAG to improve the relevance of AI-generated responses.
- Provide a simple interface for interacting with project information.

## 💬 AI Project Assistant

Users can interact with the AI assistant using natural-language questions.

Example questions:

- What is this project about?
- Explain the project requirements.
- Summarize the uploaded project document.
- What are the current project tasks?
- What are the open issues?
- Show project-related information from GitHub.
- Explain a particular requirement.

## Overall Learning 

During this course, I gained hands-on experience in developing an Enterprise AI Project Management Assistant that combines Generative AI, Large Language Models (LLMs), Retrieval-Augmented Generation (RAG), LangChain, Python, FastAPI, and database technologies. I learned how to build an AI-powered assistant that can understand project-related documents, retrieve relevant information, and provide context-aware responses. I also gained practical knowledge of document processing, embeddings, vector databases, API development, authentication, testing, and integrating AI with backend systems. Along with technical skills, I strengthened my problem-solving, debugging, teamwork, documentation, project architecture, and real-world software development skills. This project helped me understand how AI technologies can be applied to solve practical enterprise project management problems.
